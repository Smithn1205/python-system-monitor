# Python System Monitor

A simple Python system monitoring script for DevOps and Jenkins practice.

## What it does

The script collects and displays:
- Hostname
- Operating system and version
- System architecture
- Python version
- Disk space and disk usage
- Current user
- Home directory
- Current working directory
- Report generation time

It also displays a warning when disk usage is high.

## Requirements

- Python 3

The script uses only Python's standard library, so no external packages are required.

## Run locally

    python3 monitor.py
